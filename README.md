# IPL Data Analysis Dashboard – Power BI

## 1. Project Overview
An IPL data analytics project using Microsoft Power BI to explore Indian Premier League match data and identify trends in team performance, toss decisions, venues and match outcomes.

## 2. Project Objectives
- Analyse team-wise match wins and performance.
- Examine the relationship between toss decisions and match outcomes.
- Identify venue-wise match trends.
- Explore player of the match statistics.
- Analyse winning margins by runs and wickets.
- Examine matches affected by the Duckworth-Lewis (D/L) method.

## 3. Dataset Description
The project uses an IPL match-level dataset containing:

- **577 match records**
- **17 columns**

Key attributes include:
- Season and Match Date
- Competing Teams
- Toss Winner and Toss Decision
- Match Winner and Result
- Winning Margin (Runs/Wickets)
- Player of the Match
- Venue
- Umpire Details
- D/L Applied Indicator

## 4. Tools & Technologies
- **Microsoft Power BI:** Dashboard development and data visualisation.
- **CSV:** Dataset storage and handling.
- **Data Analytics:** Exploratory analysis and performance comparisons.

## 5. Dashboard Overview

The dashboard contains three analytical pages:

### Page 1 – Toss & Team Analysis
- Venue-wise toss decision distribution.
- Toss winner and toss decision analysis.
- Player of the match statistics.
- Team-wise match wins.

### Page 2 – Match Outcome Analysis
- Team-wise results by toss decision.
- Overall team performance.
- Venue-wise match distribution.
- D/L-affected match analysis.

### Page 3 – Winning Margin Analysis
- Winning margins by runs.
- Winning margins by wickets.
- Season-based filtering.
- Venue mapping and geographical analysis.

## 6. Key Analytical Areas
- Team performance and winning trends.
- Toss decision patterns.
- Venue-based match distribution.
- Player performance recognition.
- Match-winning margins.
- D/L-affected matches.

## 7. Project Files
- `IPL.pbix` – Power BI dashboard.
- `IPL Dataset.csv` – IPL match dataset.

## 8. Project Type
Data Analytics & Business Intelligence Project

**Domain:** Sports Analytics  
**Tool:** Microsoft Power BI  
**Dataset:** Indian Premier League (IPL)
